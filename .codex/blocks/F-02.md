### Current Visual System

- Palette: deep navy background (`#06284f` family), white text, translucent white grid/borders, orange accent (`#ff6b35`).
- Typography: Inter for prose/interface, IBM Plex Mono for technical labels.
- Layout: max-width 1440px, 12-column grid, 120px desktop side padding, 24px gutters, 72px section gaps.
- Motifs: blueprint/spec box, target mark, technical borders, microscopy imagery, inline schematic logo.
- Responsive behavior: collapses to single-column layouts under 900px, tighter typography under 580px.

### Technical Risks

- HTML is a single static document with inline CSS and embedded base64 images, currently about 3.8 MB.
- Assets need extraction, naming, compression, explicit dimensions, and lazy loading below the fold.
- Some semantic content is rendered as long paragraphs; production page should improve scanning without rewriting scientific claims casually.
- `♻` icon should be replaced for brand consistency and accessibility.
- `mailto:` is acceptable for MVP but weak for conversion tracking and form validation.
- Need final decision on framework, deployment target, and analytics/contact requirements before implementation.
