# AMMatz Architecture Notes

Last updated: 2026-08-15

## Intended Stack

To be confirmed in Phase 1. Default recommendation unless changed:

- Next.js App Router with TypeScript
- shadcn/ui for composable UI primitives where useful
- Tailwind CSS with semantic tokens
- Static-first content model for the initial landing site
- Production deployment target to be selected in hosting block

## Design Inputs

- Existing HTML blueprint imported into Figma as a raw-frame reference.
- Existing visual language: deep navy background, white technical typography, orange accent, grid/technical markers, industrial imagery.
- UI UX Pro Max generated a baseline design system under `design-system/ammatz/MASTER.md`.

## Design Constraints

- Keep AMMatz industrial, precise, credible, and technical.
- Use the generated design system as a starting point, not a binding replacement for the current brand.
- Avoid generic SaaS gradients, decorative blobs, emoji icons, and over-playful startup styling.
- Maintain strong responsive behavior at 375, 768, 1024, and 1440px.

## Open Decisions

- Final frontend stack confirmation.
- Hosting provider and deployment workflow.
- Final content and imagery source of truth.
- Analytics/contact form requirements.
